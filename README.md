# 苏轼行迹图

苏轼一生三十站的可交互地图：每一站的经历、大事和诗词文全文，可全文检索，也可按人物查看。

在线查看：https://pippobenben57-cmd.github.io/sushi/

来源与说明见页面底部。诗词正文来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT），文章正文来自维基文库（CC BY-SA 4.0）。

背景琴声：《醉渔唱晚》（CC BY-SA 3.0）与《平沙落雁》（CC BY 2.5），Charlie Huang 演奏并录音，取自 [维基共享资源](https://commons.wikimedia.org/wiki/Category:Guqin_music)；已转为单声道 MP3 并调整音量，沿用原许可。
